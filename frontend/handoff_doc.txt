## 🧠 What It Does

**WolfieDex** is a Pokémon/GameBoy-themed AI event assistant for Stony Brook University students. You ask it questions about campus events — in plain English or via quick-tap filter chips — and it responds in a retro chat interface.

**Two screens:**
- **Home** — pixel art background, animated typewriter search box, 5 filter chips (Today, Free Food, Late Night, Sports, Career). Clicking a chip or pressing Enter transitions into chat mode.
- **Chat** — blurred background, scrollable message history with query and response bubbles, persistent bottom input bar. Supports follow-up questions.

**Flow:**
1. User types a query or taps a chip
2. Chip labels get expanded into full natural-language queries via `expandQuery()` before being sent
3. A 300ms fade transition plays between screens
4. The response appears character-by-character via a typewriter effect (40ms/char)

## 🛠 Tech Stack

| Layer | Tool |
|---|---|
| Framework | **Next.js 14** (App Router) |
| Language | **TypeScript** |
| Styling | **Inline React styles** + custom CSS classes in `globals.css` |
| Font | **Press Start 2P** via `next/font/google` (self-hosted) |
| CSS Framework | **css-pokemon-gameboy** (CDN) for pixel aesthetic |
| Images | **Next.js `<Image>`** component with `imageRendering: pixelated` |
| Animation | CSS `@keyframes` (blinking cursor), JS `setInterval` (typewriter), CSS `opacity` transition (screen fade) |
| State | React `useState`, `useEffect`, `useRef` |
| Routing | Next.js App Router (single-page, state-driven screen switching) |
